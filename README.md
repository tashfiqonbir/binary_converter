# ✨ Binary Converter CLI Tool

A clean, user-friendly, and lightweight Python command-line utility to encode plain text into space-separated 8-bit binary code and decode binary code back into human-readable text.

## 🚀 Features
- **Text to Binary (Encode):** Instantly converts alphabets, numbers, and symbols into 8-bit binary format.
- **Binary to Text (Decode):** Converts space-separated or continuous binary strings back to readable text.
- **Clean Interface:** Terminal screen auto-clears for an organized and distraction-free user experience.
- **Error Handling:** Gracefully handles invalid inputs and empty fields.

## 📋 Prerequisites
Make sure you have [Python 3.x](https://python.org) installed on your system. You can check if Python is installed by running this command in your terminal:
```bash
python --version
```

## ⚙️ How to Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/tashfiqonbir/binary_converter
   ```
2. **Navigate to the project directory:**
   ```bash
   cd binary_converter
   ```
3. **Run the script:**
   ```bash
   python binary_converter.py
   ```

## 💡 Usage Guide
- Select option `1` from the main menu to type any text and get its binary representation.
- Select option `2` to input binary numbers and instantly decode them back to plain text.
- Select option `3` to exit the tool cleanly.
